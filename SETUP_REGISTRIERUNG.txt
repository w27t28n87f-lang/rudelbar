RUDELBAR v70 – EINMALIGE EINRICHTUNG

1. supabase_setup_v70.sql im Supabase SQL Editor komplett ausführen.
   Dabei wird automatisch der älteste bereits vorhandene Auth-Benutzer als Admin gesetzt.

2. In Supabase Authentication die öffentliche Registrierung deaktivieren.
   Wichtig: Nur dann ist eine Registrierung außerhalb der Rudelbar-Einladungsfunktion gesperrt.

3. Die Edge Function "register-invite" aus dem Ordner
   supabase/functions/register-invite/index.ts deployen.
   Sie muss ohne JWT-Prüfung erreichbar sein, weil der neue Benutzer vor der Registrierung
   noch nicht angemeldet ist. Die Funktion prüft stattdessen den einmaligen geheimen Token.

4. Danach die Webdateien aus diesem Paket auf GitHub Pages hochladen:
   index.html
   style.css
   app.js
   manifest.json
   service-worker.js
   Logo-Haupt.png
   Logo-Mobile_Kneipe.png
   Logo-Mode.png
   Logo-Service.png

5. Als bisheriger Admin einloggen. Auf der Startseite erscheint "Einladungen".
   Dort einen persönlichen Link erstellen und über Teilen an die gewünschte Person senden.

6. Der Link ist einmalig und läuft nach der gewählten Frist ab.
   Ohne ?invite=... wird in der App keine Registrierung angeboten.

SICHERHEIT
- Der Supabase Service-Role-Key gehört ausschließlich in die Edge Function und niemals in app.js.
- Die App verwendet weiterhin nur den Publishable/Anon Key im Browser.
- Einladungslinks wie Passwörter behandeln: nicht öffentlich posten.
